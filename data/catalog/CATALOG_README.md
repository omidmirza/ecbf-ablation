# N200 display catalog (paper source of 12 October 2026)

Every N200 table and figure, in the paper and the report style, with a table of contents, a list of tables and
(display catalog) a list of figures. Every caption gives the file, the data source and the exact line that restores
the display in an edition of the paper (arXiv version, ablation report, or the unpublished extended version). The
catalogs were built from the state of the paper source on 12 October 2026; where they differ from
`pdf/ablation_report.pdf`, the report is the current version.

## PDFs (`pdf/catalog/`)

| PDF | Content | Pages |
|---|---|---|
| `display_catalog_paper.pdf` | paper style (ieeeconf, one column, 505.89 pt, 10 pt): 87 tables (42 edition + 45 catalog), 307 figures (134 edition + 173 catalog) | 579 |
| `display_catalog_report.pdf` | report style (article 11 pt Times, 505.89 pt): 69 tables (24 edition + 45 catalog), 270 figures (113 edition + 157 catalog) | 732 |
| `sweeps_full_{paper,report}.pdf` | full sweep tables, alpha0 = 0.10 ... 0.30, Corridor and Maze (alpha -> delta -> K -> four variants, all metrics): 10 tables | 163 / 263 |
| `sweeps_compact_{paper,report}.pdf` | compact sweep tables (best variant per setting): 10 tables | 27 / 25 |
| `sweeps_a030_{paper,report}.pdf` | alpha0 = 0.30 only, compact and full: 4 tables | 63 / 95 |

Each catalog comes in two styles (paper and report), and each style has its own preamble (ieeeconf or article).
Display catalog order: front matter (how to read, caption abbreviations [F] [A] [T] [V] [C], key, delta_1 equation);
I tables in the editions; II-IV catalog tables (default and selected settings, parameters with all four variants,
checks and events); V compact sweeps; VI full sweeps; VII figures in the editions; VIII catalog figures
(distributions, sweep plots, trajectory maps, heatmaps by scenario -> metric -> alpha0 -> delta).

Naming: the settings T1-T5 in captions (New1-New5 in file names) are the settings S1-S5 of the paper and the report.
Reference numbers with the prefix A (for example Table A.I) are those of the arXiv version of the paper.

## Values

`data/catalog/catalog_values.json.gz` and `code/tools/n200_tables/catalog_values.json.gz` are the same file: every
printed cell of the catalog tables (157,936 cells) with its fragment, row, method, metric and view id, as generated
on 12 October 2026 by `build_tables.py --catalog`. These are the values the catalog PDFs were built from. Input paths
are given relative to the N200 summary exports (`N200_numbers/...`, not included).

## Files

In this folder (`code/catalog/`):

- `build_catalog.py`: writes the bodies and wrappers, compiles the 8 PDFs and checks the logs.
- `preamble_paper.tex`, `preamble_report.tex`: style preambles (they load the paper or report preamble of the paper
  source and turn the revision-highlight colours off, so all text prints in black).
- `catalog_macros.tex`: front matter (title, how to use the catalog, abbreviations, key).
- `display_catalog.tex`, `sweeps_full.tex`, `sweeps_compact.tex`, `sweeps_a030.tex`: document masters (front matter,
  table of contents, lists).
- Generated by `build_catalog.py` (not stored): `<doc>_{paper,report}.tex` (wrappers) and
  `generated/<doc>_body_<style>.tex` (bodies).

Elsewhere in this repository: `code/tools/n200_tables/` (table generator `build_tables.py` and `catalog_tables.py`,
checks `check_tables.py`, colour switch `table_colour.py`, values `catalog_values.json.gz` and
`tables_values.json.gz`) and `pdf/catalog/BUILD_RESULTS.json` (log check of the shipped PDFs).

Not included (part of the paper's LaTeX source): `paper_helper.tex`, `release_helper.tex`, `report/report_helper.tex`,
`report/generated/paper_references.tex` (reference numbers of the arXiv version), `appendices/n200_assets.tex`, the
table fragments `appendices/generated_n200/{paper,report,catalog}/` (manifest `CATALOG_TABLES.json` with view ids,
hashes and restore lines), the figures `figures/n200/{paper,report,catalog}/` (manifest `CATALOG_FIGURES.json`) and
`sections/`. The catalogs can therefore only be rebuilt inside the paper source tree; the captions name files by
their path in that tree.

## Build

Requirements: Python 3, pdflatex with latexmk, and pdfinfo (poppler). Copy `code/tools/` to `tools/` and
`code/catalog/` to `catalog/` of the paper source tree, then run from its root:

    python3 tools/n200_tables/build_tables.py --catalog   # edition fragments + catalog fragments
    python3 tools/n200_tables/check_tables.py              # ERRORS: 0 (editions and catalog)
    python3 catalog/build_catalog.py                       # bodies + latexmk of the 8 wrappers

`build_catalog.py` checks the hashes of all catalog tables and figures, compiles from the paper source root and
reports LaTeX errors, undefined references, pending assets, Overfull boxes, table-layout warnings and any table that
spans a different number of pages than its fragment's `\ntablebreak` count + 1; it prints `CATALOG BUILD: PASSED`
only when all of these are zero and writes the counts to `pdf/catalog/BUILD_RESULTS.json`. For the shipped PDFs:
no LaTeX errors, undefined references, pending assets or Overfull boxes; two table-layout warnings (column
separation below 1 pt) in `display_catalog_paper.pdf`; and in `display_catalog_report.pdf` the tables
`topfive_full_corridor` and `topfive_full_maze` span 3 pages instead of 2. The script therefore ends with
`CATALOG BUILD: FAILED` for these two layout checks.

## Catalog table fragments (both styles)

`sweep_{scen}_a{010..030}`, `compact_{scen}_a{010..030}`, `{delta,period,b,lmu}_all_{scen}`,
`phi_all_{scen}_{L0005,L005}`, `checks_all_{scen}_{L0005,L005}`, `detailed_events_all_{scen}`, `topfive_events`,
`default_{scen}`, `topfive_{scen}` (default + T1-T5, all metrics), `topfive_full_{scen}`.

Compact rule (key box of each compact table): per setting the certified variant with the most best means (bold
rule of the key) among m_c/c_max, q+_CBF, q+_unsafe, T_mis, shown in its own column as "Variant (k)" with k = number
of columns where it is best; ties in k: smaller printed m_c/c_max, then q+_unsafe, q+_CBF, T_mis, then V-U, V-Delta,
V-L, V-C. `check_tables.py` re-derives the variant and k from the exports for all 1,500 rows (750 per style).

## Restoring a display in an edition (paper source tree)

- Edition table: `\ntable{<name>}` (the caption lists where it is used now).
- Catalog table: `\ntable{../catalog/paper/<name>}` (arXiv and extended version) or
  `\ntable{../catalog/report/<name>}` (report); `appendices/n200_assets.tex` prefixes `appendices/generated_n200/<kind>/`.
  Layout tags start with `Q`, so they never clash.
- Catalog figure: `\nfigure{../catalog/<style>/<subdir>/<file>.pdf}` (`[\columnwidth]` for 245.72 pt maps).
- Edition figure: the `\nfigure` line given in its caption.

These lines are exactly what the catalog documents themselves compile, so each is tested.
