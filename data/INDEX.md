# Index of displays

One row per figure and table of the arXiv paper and of the ablation report (`pdf/ablation_report.pdf`), with the data files in this folder and the script that draws it. Paths in the data columns are relative to this folder (`data/`); `code/tools/...` paths are relative to the repository root; `appendices/...` and `figures/...` paths are relative to the paper source tree (not included). Edition: A = arXiv paper, R = ablation report. Labels are the LaTeX labels of the displays in the paper source. N200 is the study with N = 200 trajectories per configuration.

Settings: default (0.15, 0.10, 0.05, 50) V-C; S1 (0.30, 0.25, 0.20, 50) V-C; S2 (0.30, 0.25, 0.15, 50) V-C; S3 (0.30, 0.20, 0.20, 50) V-L; S4 (0.30, 0.25, 0.025, 100) V-Delta; S5 (0.30, 0.25, 0.10, 10) V-C, as (alpha0, alpha, delta, K) and paired variant. S1..S5 of the paper and the report are named T1..T5 in the data files and New1..New5 in figure file names (the table data use S1..S5).

The CSV files were written by `tools/build_dump.py` from the N200 summary exports, and `COLUMNS.csv` and this index by `tools/make_docs.py`. A display is redrawn from the exports only by its script in `code/tools/...` (no simulation). The figure and heatmap commands below run inside this repository and need the external inputs named in the repository README (`ECBF_N200_NUMBERS`, `ECBF_N200_DATA`, `ECBF_FIGURE_STYLE`); the table builder runs in the paper source tree (README, Rebuilding, step 1). The scripts write their PDFs to the `--out` folder given.
