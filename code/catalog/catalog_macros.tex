  \section*{How to use this catalog}
  {\sloppy Every caption names the file, the data it was generated from and the exact line that restores the display
  in an edition of the paper (the arXiv version, the ablation report or the unpublished extended version). File
  paths are relative to the root of the paper's LaTeX source; its \texttt{tools/} and \texttt{catalog/} folders are published as \texttt{code/\allowbreak{}tools/}
  and \texttt{code/\allowbreak{}catalog/} of the code and data repository, while the other source folders
  (\texttt{sections/}, \texttt{appendices/}, \texttt{figures/}, \texttt{report/}) are not included there. Numbers
  with the prefix A (for example Table~A.I or Appendix~A.E-A) are those of the arXiv version of the paper.
  The settings T1--T5 of the captions (New1--New5 in file names) are the settings S1--S5 of the paper. Table fragments
  of the catalog are restored with \texttt{\textbackslash ntable\{../\allowbreak{}catalog/\allowbreak{}<style>/\allowbreak{}<name>\}} (the macro
  \texttt{\textbackslash ntable} of \texttt{appendices/\allowbreak{}n200\_assets.tex} reads
  \texttt{appendices/\allowbreak{}generated\_n200/\allowbreak{}<edition style>/\allowbreak{}}); figures of the catalog with
  \texttt{\textbackslash nfigure\{../\allowbreak{}catalog/\allowbreak{}<style>/\allowbreak{}<path>\}}, inside the float and caption of the edition.
  Table values are generated by \texttt{tools/\allowbreak{}n200\_tables/\allowbreak{}build\_tables.py} (\texttt{-{}-catalog} for the catalog
  fragments) and re-derived from the exports by \texttt{tools/\allowbreak{}n200\_tables/\allowbreak{}check\_tables.py}. The level at
  $K=\infty$ used by the check marks is
  \begin{equation}\delta_1=\frac{\delta}{2b\ln^2 2}.\label{eq:empirical-first-test-budget}\end{equation}
  Abbreviations in the captions ([F], [A] and [T] are files of the N200 summary exports, which are not included in the
  repository):\par
