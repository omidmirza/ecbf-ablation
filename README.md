# ecbf-ablation

Code and data for the ablation study of "Anytime-Valid Certification of Robustness Margins for Safe Control via
E-Values" (Trakas, Mirzaeedodangeh, Lindemann, 2026).

## Contents

| Folder | Content |
|---|---|
| `pdf/ablation_report.pdf` | The ablation report, current version (111 pages: implementation details, all sweeps, heatmaps, trajectory maps and distributions per setting, the additional S* comparison, and the reference to the arXiv version of the paper). |
| `pdf/catalog/` | Display catalogs in paper and report style (`display_catalog_*`, `sweeps_{a030,compact,full}_*`), built on 21 October 2026 from the paper source as of 15 October 2026, with the table fragments regenerated by the code of this repository and the figure files of that source, in which every printed figure is the printed version (see `code/catalog/README.md`). Where they differ from the report (for example in wording or captions), the report is the current version. Their captions name files of the paper's LaTeX source (`appendices/`, `sections/`, `figures/`) and the line that includes each display; that source is not part of this repository. |
| `data/` | The display data behind every figure and table (CSV, JSON, Markdown) and the summary metrics `data/metrics/{final,new_anchors}/metrics.json.gz` (N = 200 trajectories per setting, seeds 970001-970200: means, standard deviations, event counts and uncertainty per cell; `final` covers the unified grid, `new_anchors` the added anchor settings). Start with `data/README.md`, `data/INDEX.md` (one row per display, with its printed figure or table number), `data/COLUMNS.csv` (column definitions) and `data/VERIFICATION.md`. |
| `code/simulation` | The simulation package `ecbf` that generated the trajectories (dynamics and nominal controllers, CBF filter, e-value tests and certification, the risk-increase terms of V-U, V-Delta, V-L and V-C, geometry, risk evaluation and assessment) and `run_example.py`, which runs one trajectory. Section 1 of the report gives the implementation details this code follows. `code/simulation/README.md` maps each module to the report's terms. |
| `code/tools/n200_tables` | Table builder `build_tables.py` (all table fragments; `--catalog` also writes the catalog fragments of `catalog_tables.py`), `table_colour.py` (coloured and plain version of each table), `check_tables.py` (re-derives every printed value), `compile_tests.py` (compiles every fragment at its target width; `--catalog` compiles the catalog fragments after `build_tables.py --catalog`; test documents in `test/`), `paper_source.py` (reads text of the paper source and removes its one-argument edit marks; used by `build_tables.py` and `check_tables.py`), `KEY_LINES.md` (table key, caption notes and list of fragments), `starred_setting.json` (values of the starred row S*), `tables_values.json.gz` (every printed table value of the current build), and `build_tables_v10_original.py` and `check_tables_v10_original.py` (the base table generator and its check, which `build_tables.py` extends; kept for reference, with input paths and docstrings adapted). |
| `code/tools/n200_figures` | Figure builders and their caches: `extract_sweep_cells.py` (sweep cells from the exports, cache `sweep_cells.json`), `load_setting_assessments.py` and `load_default_assessments.py` (per-trajectory values from the saved assessments, caches `setting_assessments.json` and `default_assessments.json`), `build_sweeps_box.py` (box-plot sweeps of S3 in the arXiv paper, cache `sweepbox_T3_values.json`), `build_sweeps_box_ext.py` (box-plot sweeps of every setting in the report, cache `sweepbox_ext_values.json`), `build_sweeps.py` and `build_sweeps_twin.py` (line-plot sweeps, not printed), `build_distribution_figures.py` (per-trajectory distributions), `build_theorem_checks_box.py` (theorem checks), `build_default_figures.py` (default-setting figures) and `n200_style.py` (shared styles). |
| `code/tools/n200_maps` | Report trajectory maps (`build_maps_report.py`, `build_maps_report_pair.py`; the report prints the pair maps). |
| `code/tools/n200_heatmaps` | Heatmap builder `build_heatmaps.py` and `run_heatmaps.sh`, which draws the printed heatmaps. |
| `code/tools/n200_catalog`, `code/catalog` | Copies of the figure builders with the catalog variants (`run_catalog_heatmaps.sh`) and the catalog builder `build_catalog.py` (see `code/catalog/README.md`). |

The selected settings S1-S5 of the paper and the report carry the labels T1-T5 (asset labels New1-New5) in the data
files and scripts.

## Requirements

Python 3.12 with numpy and matplotlib (`code/simulation` also needs scipy), a LaTeX installation with `pdflatex` and
`latexmk` (all figure text is set with `text.usetex`), poppler (`pdfinfo`, used to check figure widths) and bash for the
two heatmap scripts (`PYTHON=...` selects their interpreter, default `python3`).

## What runs with the files of this repository

Commands from the repository root.

1. One trajectory (Python 3.12 with numpy and scipy). The command below reproduces the row of the default setting for
   seed 970001 in `data/per_trajectory/per_trajectory_values.csv`; `code/simulation/README.md` explains the output.

   ```sh
   cd code/simulation
   python3 run_example.py --scenario corridor --variant V-C --alpha0 0.15 --alpha 0.10 \
       --delta 0.05 --K 50 --b 2.11 --phi 1.0 --L-mu 0.0005 --seed 970001
   ```

   The arguments are the scenario, the variant (or a baseline), the CBF-violation probability $\alpha_0$, the margin
   insufficiency $\alpha$, the error confidence $\delta$, the test period $K$, the budget normalizer $b$, the bound
   factor $\phi$, the distribution-drift bound $L_\mu$ and the seed. The study uses the seeds 970001 to 970200
   ($N_{\mathrm{MC}} = 200$ per setting); the scripts that scheduled the full set of runs are not included.
2. Checksums of the data: `cd data && shasum -a 256 -c SHA256SUMS.txt`.
3. Column dictionary and display index: `cd data && python3 tools/make_docs.py` rewrites `COLUMNS.csv` and
   `INDEX.md` from the files of `data/`.
4. Figures from the shipped caches. These builders also need the figure helper `ieee_figure.py` (strict save: vector
   PDF at the final width, text-size and line-width checks), which is not included; set `ECBF_FIGURE_STYLE` to its
   folder. They write PDFs and a manifest to the `--out` folder:

   ```sh
   cd code/tools/n200_figures
   python3 build_sweeps_box.py --omit-zero-rows --out out_paper                  # arXiv Fig. 8
   python3 build_sweeps_box_ext.py --kind report --out out_report                # report Figs. 19-30 (*)
   python3 build_distribution_figures.py --kind report --out out_report --form half   # report Figs. 13-18
   python3 build_sweeps.py --kind paper --out out_paper                          # line-plot sweeps (not printed)
   python3 build_sweeps_twin.py --out out_paper                                  # (not printed)
   python3 build_default_figures.py --kind report --out out_report               # default setting (not printed)
   ```

   (*) with `--reload` (needs `ECBF_N200_DATA` and `ECBF_N200_NUMBERS`) it also writes
   `data/sweeps/sweepbox_ext_values.csv`, the uncompressed form of `sweepbox_ext_values.csv.gz` (folder
   `ECBF_DISPLAYS`). In some rebuilt report sweep figures the tick labels of the error confidence $\delta$ sit up to
   about 1 pt from their printed position; text and drawings are otherwise the same. `data/INDEX.md` gives the command
   of each printed figure.

## What needs inputs that are not included

The inputs below are named by environment variables. Each defaults to the file or folder named in the table, at the
repository root (computed from the script's location under `code/` or `data/`):

| Variable | Default | Content |
|---|---|---|
| `ECBF_N200_NUMBERS` | `N200_numbers/` | summary exports of the N = 200 runs (not included): `{final,new_anchors}/common/metrics.json`, `{final,new_anchors}/common/population.jsonl`, `{final,new_anchors}/temporal/temporal_metrics.json` |
| `ECBF_N200_DATA` | `N200_data/` | trajectory index `N200_INDEX.sqlite` and the saved per-trajectory assessments it points to (not included) |
| `ECBF_N100_CATALOG` | `N100_data/runs.sqlite` | run catalog of the N = 100 runs, seeds 970001-970100 (source `n100_prefix_sealed` of the index; not included) |
| `ECBF_CANDIDATES` | `candidate_review.json` | candidate review of the unified grid, read by the table builder (not included) |
| `ECBF_FIGURE_STYLE` | `figure_style/` | figure helper `ieee_figure.py` (not included) |
| `ECBF_MAPS_BUILDER` | `maps_top5/build_maps_top5.py` | trajectory map builder (not included) |
| `ECBF_DISPLAYS` | `data/` | display data folder of this repository (the box-plot builders write their CSV files there when they rebuild their caches with `--reload`; `build_sweeps_box_ext.py` writes `sweeps/sweepbox_ext_values.csv` uncompressed) |
| `ECBF_PREVIOUS_SETUP` | `appendices/f_tab_setup_previous.tex` of the paper source tree | optional: an earlier version of the parameter table (arXiv Table III); when the file exists, `check_tables.py` also checks that its rows are unchanged, otherwise it skips that comparison with a note |

What each part needs:

- Exports (`ECBF_N200_NUMBERS`): `data/tools/build_dump.py` and
  `data/tools/verify_sample.py`; in `code/tools/n200_figures`, `extract_sweep_cells.py` and
  `build_theorem_checks_box.py`; the heatmaps (`code/tools/n200_heatmaps/run_heatmaps.sh`, or
  `build_heatmaps.py --help` for single figures); the table builder and its check.
- Saved assessments (`ECBF_N200_DATA`, `ECBF_N100_CATALOG`): refreshing the per-trajectory caches with
  `load_setting_assessments.py`, `load_default_assessments.py`, or `build_sweeps_box.py --reload`.
- Trajectory maps: the raw trajectory payloads (about 54 GB) and the map builder `build_maps_top5.py`
  (`ECBF_MAPS_BUILDER`); `code/tools/n200_maps/build_maps_report*.py` call it with the report width and text size.
- Tables and catalogs: the paper's LaTeX source tree (below).
- The report itself is compiled from the paper source with `latexmk -pdf versions/03_ablation_report.tex` (source not
  included).

## Rebuilding

The figure, heatmap and map builders run in place in this repository (paths below are relative to the repository
root) and write to the folder given by `--out`. The table and catalog builders need the paper's LaTeX source tree:

1. Copy `code/tools` and `code/catalog` into the paper source tree as `tools/` and `catalog/`, next to `main.tex` and
   `figures/`. The table and catalog scripts write their fragments and PDFs relative to that tree. After copying, the
   defaults above resolve relative to the copy, so set every `ECBF_*` variable, with `ECBF_DISPLAYS` pointing to the
   `data/` folder of this repository.
2. Tables, from the root of the paper source tree: `python3 tools/n200_tables/build_tables.py`, then
   `python3 tools/n200_tables/check_tables.py` (must report 0 errors) and `python3 tools/n200_tables/compile_tests.py`
   (compiles the test documents in both styles; after `build_tables.py --catalog`, `compile_tests.py --catalog` checks
   the catalog fragments). `build_tables.py` reads the exports in `ECBF_N200_NUMBERS` and records every printed value
   in `tools/n200_tables/tables_values.json.gz`; `check_tables.py` re-derives each recorded value from the exports. A
   rebuild reproduces every printed value; the stored unrounded upper bounds can differ in the last digits.
3. Figures (`--kind paper` or `--kind report`), in `code/tools/n200_figures` of this repository: refresh the caches
   with `extract_sweep_cells.py`, `load_setting_assessments.py` and `load_default_assessments.py`, then run
   `build_sweeps_box.py --omit-zero-rows --out DIR`, `build_sweeps_box_ext.py --kind KIND --out DIR`,
   `build_distribution_figures.py --form half --kind KIND --out DIR` (the printed distribution figures are the half
   form), `build_theorem_checks_box.py --kind KIND --out DIR` (add `--setting Default` for
   `theorem_checks_<scen>_Default.pdf`) and `build_default_figures.py --kind KIND --out DIR` (default-setting figures
   that are not printed); they write vector PDFs at the final printed width and a manifest per run. Heatmaps:
   `code/tools/n200_heatmaps/run_heatmaps.sh` (output folders `out_paper/` and `out_report/` next to the script).
4. Trajectory maps: `code/tools/n200_maps/build_maps_report_pair.py` (inputs above).
5. Catalogs: see `code/catalog/README.md`.

## Data provenance

The data are the summary values of the N = 200 Monte Carlo trajectories per setting, exported on 7 October 2026 from the
simulation results (3,914 cells in `final`, 720 in `new_anchors`). `data/VERIFICATION.md` compares a sample of 50
CSV values with the exports (`data/tools/verify_sample.py`, exact equality), and `check_tables.py` re-derives every
printed table value from the exports. Raw trajectories are not included; `data/per_trajectory` holds the
per-trajectory summaries used by the displays.

## Paper

The paper links to this repository and cites the ablation report. The arXiv paper reports event frequencies and their
one-sided 95% upper confidence bounds in percent, and mean decision fractions as percentages with the sample SD. The
ablation report gives event counts out of N = 200; the certificate number is a count per trajectory.
